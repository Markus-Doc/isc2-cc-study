Reprograms how you answer questions. Read this first because it changes how you interpret everything else. Every subsequent document and quiz session should be filtered through these 10 rules.

## Step 3: Tricky Distinctions

## Step 4: Question Bank (115 Questions)
Read through the full Q&A bank with rationale. Don't quiz yourself yet — just absorb the question patterns, answer styles, and ISC2 reasoning. Pay attention to the qualifiers (MOST, BEST, FIRST, PRIMARY, NOT).

## Step 5: CAT Quiz Simulator — Domain Drills
Run domain-filtered sessions on any domains where you hesitated during Step 4. Use 25-question sets. Review every missed question's rationale before moving to the next domain.

## Step 6: CAT Quiz Simulator — Full Mock Exam
Run a full 100-question timed session. Commit to each answer like the real exam — no second-guessing after confirming. Review the results screen and re-read rationale for every miss.

## Step 7: Re-read Any Flagged Sections
Go back to anything from Steps 2–3 that you flagged as shaky. One targeted pass is worth more than a full re-read of everything.

## Step 8: Cheat Sheet
Read once the night before, once the morning of. Pure short-term memory loading — everything you need at instant recall compressed onto one page.
