100. An IT administrator notices that data packets from a user's computer are not reaching the destination server due to issues with logical addressing. Which layer of the TCP/IP model should the administrator investigate to resolve the problem?

 A. Application Layer
 B. Transport Layer 
 C. Internet Layer 
 D. Network Interface Layer
Correct Answer: C. Internet Layer Explanation: The correct answer is (C) because the Internet Layer of the TCP/IP model is responsible for logical addressing and routing, primarily through the use of IP addresses. If data packets are not reaching their destination, the administrator should check IP configurations, routing tables, and subnetting. (A) Application Layer handles user-facing protocols and interfaces but does not deal with addressing or routing. (B) Transport Layer is responsible for end-to-end communication and data segmentation but relies on the Internet Layer for addressing. (D) Network Interface Layer focuses on hardware-level communication, such as MAC addresses and physical connections, and does not address logical routing issues.
