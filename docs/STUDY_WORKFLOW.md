# Study Workflow

## Daily Cram Flow

1. Open the drill trainer
2. Run through all due cards
3. Mark weak items honestly
4. Review weak items again
5. Open the quiz player
6. Complete a question set
7. Review incorrect answers
8. Convert repeated mistakes into new drill cards

## Final Exam Cram Flow

1. Review weak drill cards
2. Complete one full quiz pass
3. Review every incorrect answer
4. Review acronyms and definitions
5. Review ISC2 CC domains
6. Stop adding new material close to exam time unless it fixes a clear weak point

## Weak Area Tracking

Common weak areas should be tracked by domain.

Suggested domains:

- Security Principles
- Business Continuity, Disaster Recovery, and Incident Response Concepts
- Access Controls Concepts
- Network Security
- Security Operations

## Rule for Mistakes

Every wrong answer should become either:

- A corrected quiz explanation
- A new drill card
- A weak area note

## Practical Exam Preparation Rule

Do not only memorise answers. For each wrong answer, learn why the wrong options were wrong.
